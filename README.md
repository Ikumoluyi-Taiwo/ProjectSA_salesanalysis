# ProjectSA_salesanalysis
# Sales Analysis using SQL and Excel Integration.

## Project Overview
This project uses the Microsoft AdventureWorks sample database, a fictional multinational manufacturing and retail business dataset designed to represent real-world business operations. The dataset contains information relating to products, sales, customers, territories and other business activities.
The project focuses on analysing AdventureWorks sales data to generate insights into product and geographical sales performance. I imported the provided CSV datasets into SQL Server, wrote SQL queries to extract and analyse the required information, and used Microsoft Excel to create dashboards and visualisations.
The analysis focuses on key business metrics including sales, tax, freight and product costs, providing insights across different products, product colours, countries and regions.

## Objectives
The main objectives of the project were to:
1. Analyse total sales performance across different products.
2. Examine tax amounts by product colour.
3. Analyse freight costs associated with individual products.
4. Evaluate the proportion of total product costs by product.
5. Compare sales and freight across different countries.
6. Analyse the percentage contribution of total tax amounts across regions.
7. Present the findings in clear and accessible Excel dashboards.

## Tools Used
### Microsoft SQL Server
Used to: Create the PROJECTSA database, import and manage the AdventureWorks CSV datasets, write SQL queries to extract, aggregate and analyse the required data. Calculate sales, tax, freight, product cost and geographical performance metrics. Created **VIEWS** containing key queries for reporting and visualisation.

### Microsoft Excel
Used to: Import and organise the results of the SQL analysis, create charts and visualisations to communicate key findings, develop dashboards showing product, country and regional performance, present the analysis in an easy-to-understand format for decision-making.

## Data Analysis
### Product Performance Analysis
The first dashboard focuses on product-level performance and includes:
1. Total Sales by Product Name – identifies products generating the highest sales.
2. Total Tax Amount by Product Colour – analyses tax contributions across different product colours.
3. Total Freight by Product Name – compares freight costs associated with individual products.
4. Proportion of Total Product Cost by Product Name – shows each product’s contribution to overall product costs.

### Geographical Performance Analysis
The second dashboard focuses on geographical performance and includes:
1. Total Sales Amount and Total Freight by Country – compares sales generated and freight costs across countries.
2. Percentage of Total Tax Amount by Region – shows each region’s contribution to the overall tax amount.

## Project Workflow
The project followed an end-to-end data analysis process:
CSV Files → SQL Server → Data Extraction & Analysis → Excel → Dashboard & Visualisation
1.	Extracted the AdventureWorks CSV files.
2.	Created a database in SQL Server.
3.	Imported the CSV datasets into the database.
4.	Wrote SQL queries to join, aggregate and analyse the required data.
5.	Imported the relevant query results into Excel for reporting and created charts and dashboards.
7.	Presented the findings through product and geographical analysis.
